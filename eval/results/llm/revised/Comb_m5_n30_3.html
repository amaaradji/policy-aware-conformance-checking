4. RECOMMENDATIONS

  • Model change: Update the BPMN model to explicitly handle or restrict the occurrence of 'Unexpected Activity' in the process flow.
  • Activity policy fix: Enforce correct lifecycle transitions for Retriable activities by preventing transitions directly from failed to done in 'Verify Income'.
  • Resource policy fix: Review and adjust the 'Income Verification Service' resource configuration to ensure it only allows authorized state transitions during consumption.
  • Binding policy fix: Implement stricter checks to ensure activities only use their bound resources and that resource state changes align with activity activation periods.
