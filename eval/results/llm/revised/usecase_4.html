4. RECOMMENDATIONS

  • Update the BPMN model to enforce mandatory execution of 'Risk Assessment' after 'Credit Check' to prevent missing activities.
  • Configure the 'Credit Check' activity to strictly limit retries to a maximum of three, and implement error handling to prevent unauthorized lifecycle transitions.
  • Set up the 'Credit Bureau API' resource to automatically lock and release within the allowed 5-minute window, and reject consumption attempts exceeding this duration.
  • Revise binding rules to ensure resources cannot change state (unlock or done) while the activity is completed, and enforce time-bound consumption for all activity-resource assignments.
