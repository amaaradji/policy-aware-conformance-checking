4. RECOMMENDATIONS

  • Model change: Update the process model to explicitly handle 'Unexpected Activity' and enforce the correct order for 'Request Support' and 'Close Ticket'.
  • Activity policy fix: Restrict re-activation of 'Request Support' after it reaches the 'done' state by enforcing lifecycle constraints in the workflow engine.
  • Resource policy fix: Ensure resources like 'Resource H' cannot transition to 'consumed' state unless the associated activity is in the 'Activated' state.
  • Binding policy fix: Implement validation to prevent resource consumption events when the activity is not active, and ensure resource assignment rules are strictly followed during activity execution.
