3. CORRELATION ANALYSIS

  • Policy violations can occur independently of sequence deviations, as shown by Trace 9, which is sequence-conformant but has a binding policy violation.
  • Binding policy violations are the only type observed in this dataset, specifically involving incorrect resource assignment.

4. RECOMMENDATIONS

  • Update the BPMN model to explicitly allow or restrict the occurrence and position of 'Unexpected Activity' to resolve control-flow mismatches.
  • Implement stricter lifecycle state validation for all activities to ensure transitions follow the required state machine.
  • Enforce resource state checks so that only eligible resources in the correct state are available for assignment and consumption.
  • Configure system logic to validate that each activity consumes only its correctly bound resource, rejecting mismatches at execution time.
