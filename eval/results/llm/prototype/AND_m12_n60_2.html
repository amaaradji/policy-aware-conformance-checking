4. RECOMMENDATIONS

  • Update the BPMN model to explicitly disallow 'Unexpected Activity' and enforce the presence of 'Assign Priority' before 'Resolve Incident'.
  • Implement stricter lifecycle state checks to ensure all activities transition only through allowed states, preventing unauthorized retries or compensations.
  • Enforce resource usage rules by configuring systems to block access to resources not in the correct state or exceeding usage caps.
  • Strengthen binding enforcement so that only the resource assigned at activity activation can be consumed during execution, rejecting mismatches at runtime.
