1. PROBLEMATIC TRACES - TWO CATEGORIES

A. Control-Flow Issues

  • Trace 1: Missing 'Add to Cart' activity before 'Checkout'.
  • Trace 8: Missing 'Search Products' activity before 'Add to Cart'.

B. Policy Violations

  • Trace 2: [Binding Policy] - 'Add to Cart' used resource 'Finance Clerk' instead of the bound 'Shopping Cart Service'.
  • Trace 5: [Binding Policy] - 'Add to Cart' unlocked resource 'Shopping Cart Service' while the activity was already done.
  • Trace 7: [Activity Policy] - 'Add to Cart' with 'Shopping Cart Service' had missing activity policy enforcement.
  • Trace 8: [Activity Policy] - 'Checkout' with 'Payment Gateway' had unauthorized state transitions: notactivated→unknown and unknown→activated.

2. PERFECT-CONFORMANCE BUT NON-COMPLIANT TRACES

  • Trace 2: The activity sequence is correct, but 'Add to Cart' used an incorrect resource, violating the binding policy.
  • Trace 5: The activity sequence is correct, but 'Add to Cart' performed an invalid resource state transition, violating the binding policy.
  • Trace 7: The activity sequence is correct, but 'Add to Cart' lacked required lifecycle policy enforcement, violating the activity policy.

3. CORRELATION ANALYSIS

  • Policy violations can occur independently of control-flow deviations, as seen in traces with perfect conformance but compliance issues.
  • Activity policy and binding policy violations are both present, but binding policy violations are slightly more frequent in this dataset.
  • Sequence deviations and policy violations do not always overlap, indicating separate root causes.

4. RECOMMENDATIONS

  • Update the process model to enforce mandatory inclusion of 'Add to Cart' and 'Search Products' before 'Checkout'.
  • Implement strict lifecycle state checks for Compensatable activities to prevent unauthorized or missing transitions.
  • Configure all resources to enforce correct state transitions, especially preventing reuse or unlocking after reaching the 'Done' state.
  • Enforce binding rules so that only the correct, pre-assigned resource can be consumed by an activated activity instance.
